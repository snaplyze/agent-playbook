# agent-playbook

Репозиторий клиент-независимых промптов для агентов, работающих с кодом, и общего контракта для `AGENTS.md` других проектов. Сам этот файл — правила сопровождения репозитория, а не контракт.

## Структура
- `prompts/00-setup.md` — сценарий подключения; в его конце — «Общий контракт агента», единственный источник блока.
- `prompts/01-audit.md` … `prompts/04-publish.md` — сценарии; раздел «Основа» в них совпадает дословно.
- `scripts/check.py` — проверки согласованности; запускай после каждой правки: `python3 scripts/check.py`.

## Правила правки
- Промпты описывают возможности по сути («если среда умеет запускать подагентов») и не называют клиентов, расширений и версий.
- Общее правило живет в контракте, специфика — в сценарии. Меняя «Основу», меняй ее во всех сценариях одинаково.
- Пиши утвердительно: что делать и зачем. Запрет оставляй там, где нужно назвать конкретное опасное действие.
- Каждое изменение смысла сверяй с контрактом и остальными сценариями на противоречия.
- Номеров редакций и журнала изменений в файлах нет: история — в Git.
- Публикация — через PR в `main`; CI запускает `scripts/check.py`.
