# agent-playbook

Репозиторий самодостаточных промптов для агентов, работающих с кодом. Этот файл — правила сопровождения самого репозитория.

## Структура
- `src/rules.md` — общие правила; сборка вставляет их в каждый промпт.
- `src/scenarios/*.md` — специфика промптов; метки `{{ПАРАМЕТРЫ}}` и `{{ПРАВИЛА}}` заменяет сборка.
- `src/scenarios.toml` — названия и описания промптов, параметры; первый вариант параметра — по умолчанию.
- `prompts/*.md` — результат сборки со значениями по умолчанию; руками не правь.
- `scripts/build.py` — сборка и проверки. После любой правки в `src/` или README запусти `python3 scripts/build.py`, затем `python3 scripts/build.py --check`.

## Правила правки
- Промпты описывают возможности по сути («если среда умеет запускать подагентов») и не называют клиентов, расширений и версий.
- Общее правило живет в `src/rules.md`, специфика — в сценарии; одно и то же не повторяй в двух местах.
- Строка варианта в `scenarios.toml` — это текст, который получит агент: пиши ее как инструкцию, со смыслом значения, а не как подпись.
- Логика сборки текста есть в двух местах: `param_text`/`assemble` в `build.py` и блок `playbook` на странице. Меняя одно, меняй и другое; CI сверяет их на всех вариантах параметров через `scripts/parity.mjs`.
- Пиши утвердительно: что делать и зачем. Запрет оставляй там, где нужно назвать конкретное опасное действие.
- Номеров редакций и журнала изменений в файлах нет: история — в Git.
- Публикация — через PR в `main`; CI проверяет сборку, после слияния страница публикуется сама.
