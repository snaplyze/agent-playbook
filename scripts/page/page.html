Репозиторий на GitHub

Промпты для AI-агентов, которые работают с кодом

Каждый промпт самодостаточен: в нем цель, общие правила и шаги сценария, поэтому он работает в любом агентном клиенте без подготовки. Выберите сценарий и параметры — текст ниже обновится сразу, — затем скопируйте его и отправьте агенту одним сообщением.

    @RAIL@

Обычно запускают 01, затем 03. 00 — по желанию, один раз в проекте; 02 — когда разросся план; 04 — когда нужно доставить весь согласованный состав.

@SECTIONS@

Промпты собраны из каталога src/ репозитория @REPO@, лицензия Apache-2.0.@BUILT@
