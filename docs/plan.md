## README-1. Запятые в таблице промптов README
- Результат: в таблице промптов README текст колонок «Когда», «Результат», «Чего не делает» сохраняет запятые; неразрывный пробел остается только разделителем тысяч в колонке «Символов».
- Причина: в `readme_tables` (`scripts/build.py`) `.replace(",", " ")` применяется ко всей строке таблицы, а не к числу; сейчас так испорчены строки 12–16 README.
- Зависимости: нет.
- Приемка: `python3 scripts/build.py`, затем полная проверка из AGENTS.md; в строках таблицы README запятые на месте, числа — с неразрывным пробелом.
- Статус: TODO. Найдено ревью при подготовке репозитория к работе агентов; следующий шаг — форматировать отдельно только число.
